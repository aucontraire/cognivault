# Critic Agent

The Critic Agent generates multiple analytical perspectives on the refined query, providing diverse viewpoints and critical analysis.

## Overview

The Critic Agent:

- Generates multiple distinct analytical perspectives
- Applies critical thinking frameworks to the query
- Identifies biases, assumptions, and alternative viewpoints
- Provides structured critique with detailed reasoning
- Supports configurable perspective generation

This agent uses GPT-5 for sophisticated multi-perspective analysis with extended timeout configuration (120+ seconds) to handle complex reasoning tasks.
